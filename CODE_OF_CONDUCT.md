# Code of Conduct

## Our commitment

We want FlareWatch to be a respectful place for contributors and users. Treat people with care and keep discussions professional.

## Expected behavior

- Be respectful and considerate.
- Welcome newcomers and help them get started.
- Accept constructive criticism.
- Keep discussions focused on the project.
- Assume good intent unless there is a clear reason not to.

## Unacceptable behavior

These behaviors are not tolerated:

- Harassment, intimidation, or discrimination.
- Personal attacks or derogatory comments.
- Trolling or deliberately inflammatory remarks.
- Publishing private information without permission.
- Conduct that would be inappropriate in a professional setting.

## Scope

This Code of Conduct applies in project spaces, including:

- GitHub issues and pull requests
- Project discussions and forums
- Other communication channels related to this project

## Enforcement

Report unacceptable behavior to the project maintainers. Reports will be reviewed fairly and as promptly as possible.

Maintainers may remove, edit, or reject comments, commits, code, issues, and other contributions that violate this Code of Conduct. Contributors who do not follow it may be temporarily or permanently banned from the project.

This Code of Conduct is adapted from common open source community standards.
